# ערוץ העדכונים של "אחותי כלה" (גרסת מחשב / NetFree)

## איך זה עובד
- המשתמשת מורידה **קובץ אחד בלבד**: `achoti-kalah.html` (כ-17KB).
  כתובת קבועה: `https://hagitmualem.com/downloads/achoti-kalah.html`
- בפתיחה הראשונה הוא מוריד את האתר ושומר אותו במחשב (IndexedDB).
- בכל פתיחה נוספת האתר נפתח מהמחשב — גם בלי אינטרנט.
- ברקע נבדק המניפסט `https://hagitmualem.com/updates/manifest.js` (נטען כתג script — הערוץ שעובד ב-NetFree).
  אם יש גרסה חדשה, מורידים **רק קבצים שהשתנו**, מאמתים גודל + checksum,
  ורק אחרי שהכול ירד בהצלחה מפעילים את הגרסה החדשה בפתיחה הבאה.
- הגרסה הקודמת נשמרת. אם גרסה חדשה לא נפתחת פעמיים ברצף — חוזרים אליה אוטומטית.
- אין אינטרנט / העדכון נכשל → האתר המקומי ממשיך לעבוד רגיל.

## עדכון אוטומטי מהאתר החי (המסלול החדש)

מקור האמת הוא האתר שפורסם: `https://achotikala.com`.
פקודה אחת אורזת ממנו את גרסת האופליין:

```bash
node scripts/sync-offline-from-live.mjs            # ליבה: HTML/CSS/JS/אייקונים
node scripts/sync-offline-from-live.mjs --with-media   # כולל תמונות/PDF/גופנים
```

הסקריפט:
- מוריד את הדף החי ואת כל הקבצים שהוא מפנה אליהם,
- מחשב חתימה לכל קובץ ומדלג על כל מה שלא השתנה,
- אורז רק את החדש/שהשתנה לקבצי `.js` תחת `public/updates/parts/`,
- מוחק חלקים ישנים שאינם בשימוש,
- כותב `public/updates/manifest.js` + `manifest.json` ומעלה את מספר הגרסה
  (אם שום דבר לא השתנה — הגרסה לא עולה ולא נשלח עדכון מיותר).

אחר כך מפרסמים את האתר הזה. זהו.

## הסקריפט הישן
`scripts/build-offline-update.mjs` אורז מתוך תיקייה מקומית של בילד — נשאר לגיבוי בלבד.
המניפסט המלא הישן שמור ב-`scripts/offline-full-manifest.json`.
